# liarliar v0.1.0 Release-Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make liarliar a release-ready public repo (`adidotai/liarliar`, v0.1.0). This means fixing the audit's
gate bugs, rewriting the skill per the Skill Engineering guide, adding the claude.ai/ChatGPT upload zip, the
release workflow, community files and visuals, and verifying with isolated live runs on CLI 2.1.311 on its own
repo and on more-itertools.

**Architecture:**
- The unchanged two-file hook stays: `hooks/judge.mjs` (pure rules) and `hooks/liarliar.mjs` (I/O). Gate changes
  live only in `judge.mjs`.
- New repo-level folders:
  - `evals/`: `claude plugin eval` cases
  - `e2e/`: the headless harness
  - `assets/`: images
  - `.github/`: templates and the release workflow
- Live verification runs from scratch clones and never touches the user's global Claude Code setup, except one
  install/uninstall that is diffed against a baseline.

**Tech Stack:** Node 18+ stdlib, `node:test`, Bash (Git Bash on Windows), GitHub Actions with the `gh` CLI,
Claude Code 2.1.311 (IDE-bundled binary), headless Chrome for one PNG.

**Spec:** `docs/specs/2026-11-03-liarliar-v0.1-release-design.md`. It builds on `docs/specs/2026-10-15-liarliar-v0.1-design.md`.

**Repo:** `<repo>` is the liarliar repo root on the author's machine, branch `main`, git identity already set.
**Scratch:** `<scratch>` is this session's scratchpad. Always use the long-form path, because Claude Code blocks
Windows 8.3 short forms. The audit drafts are in `<scratch>/audit/`.
**CLI 2.1.311:** `CLAUDE_311` is the IDE-bundled binary at
`~/.antigravity-ide/extensions/anthropic.claude-code-2.1.311-win32-x64/resources/native-binary/claude.exe`.
(No absolute local paths appear in this file, per Task 1's test.)

## Global Constraints

- Node 18+ stdlib only. Zero dependencies, no network calls from hooks, no telemetry, no install scripts.
- Owner `adidotai`. URLs are `https://github.com/adidotai/liarliar`. The install id is `liarliar@liarliar`. Version
  `0.1.0` is the same in every manifest. The previous username (written `<old>` in this plan) appears in no
  committed file, case-insensitive, except the two 2026-11-03 rename docs (this plan and its spec).
- Hooks fail open, and exit 2 only for a confirmed lie. `MAX_BLOCKS = 2`. Block messages are factual statements
  under 1,000 characters.
- SKILL.md frontmatter uses only `name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`.
  The description is one line of **≤200 characters** with no `<` or `>`. The core rule is in the first 10 body
  lines.
- `liarliar.zip` contains exactly `liarliar/SKILL.md`.
- No root `CLAUDE.md`. LF endings. No absolute local paths in any committed file, docs included.
- Live runs use CLI 2.1.311 with `--setting-sources project,local --strict-mcp-config`, Sonnet, and at most 6
  agent runs (the lean budget). They never run against the user's own folders, only scratch clones.
- Both `claude plugin validate --strict .claude-plugin/plugin.json` and `claude plugin validate --strict .` stay
  green after every task.
- Publishing (`gh repo create`, push, release, visibility) is **not** done by the agent.

## Review Focus

Real-agent receipt formatting that no earlier test covered:
1. **List-marker citations:** `- $ npm test` or `* $ npm test` should still count as citations. Pinned in Task 2
   (`accepts a citation written as a list item`).
2. **Backtick-wrapped citations:** `` $ `npm test` `` should match the run `npm test`. Pinned in Task 2
   (`strips backticks around a cited command`).
3. **A stale full suite plus a fresh narrow run:** must still be blocked as stale, because the full suite was not
   re-run. Pinned in Task 2 (`a fresh narrow run does not refresh a stale full suite`).
4. **CRLF combined with the loose NO-GO spellings:** must pass. Pinned in Task 2 (`reads a loose NO-GO in a CRLF
   message`).
5. **Emoji or decoration in the verdict line** (`VERDICT ✅ GO`): read as GO. Pinned in Task 2 (`reads a decorated
   verdict`).

  - `$ lines under UNVERIFIED are not citations`:

  - `an empty $ line is not a citation and borrows nothing`:
    `done("CLAIM    x", "  $ ", "  > 3 passed", "VERDICT  GO")` with `[edit(), run("npm test")]` matches
    `/cites no command/`.
  - `accepts a citation written as a list item`: `"  - $ npm test"` and `"  * $ npm test"` with

  - `strips backticks around a cited command`: `` "  $ `npm test`" `` with `[edit(), run("npm test")]` → `null`.
